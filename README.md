# Guillermo Márquez

Landing page estática para una membresía de viajes.

## Uso

Abre `index.html` directamente en el navegador o desde Visual Studio Code con Live Server. No requiere instalación de dependencias ni proceso de build.

## Personalización

- Actualiza `guillermomp.info@gmail.com` si se usa otro correo operativo.
- Si se añade WhatsApp o redes sociales, usa enlaces reales antes de publicarlos.
- Revisa los datos legales del titular antes de publicar cambios.
